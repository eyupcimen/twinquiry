# Overview videos

Twinquiry overview videos in English (`en`), Turkish (`tr`) and German (`de`).

Each MP4 is 50 seconds, 1080 × 1920, H.264 with AAC audio. Matching JPEGs provide README previews. Videos contain music and on-screen text, with no narration.

The diagrams explain the command-line workflow; they do not depict a separate graphical application. The demo is synthetic, not a live model benchmark.

The soundtrack was composed for these videos. Typography uses Geist, licensed under the SIL Open Font License; see `Geist-OFL.txt`.
